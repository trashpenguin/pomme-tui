# Pomme TUI 0.2.6-rc.5 — Windows setup

**Download `pomme-tui-0.2.6-rc.5-setup-x64.exe`, run setup, then open Pomme and sign in.**

- Setup checks and installs missing Chrome/Widevine, Microsoft Visual C++ x64 Runtime and WebView2 from official Google/Microsoft downloads. Working components are reused.
- Downloaded installers must pass trusted publisher signature verification. Windows may ask for administrator permission to install prerequisites.
- Adds a Start menu shortcut, offers a desktop shortcut and registers an uninstaller. Uninstall keeps your Pomme profile and shared prerequisites.
- If a prerequisite requires a restart, setup asks you to restart manually before opening Pomme. It does not initiate a reboot.

You still need **Windows 10/11 x64, internet access and your own active Apple Music subscription/sign-in**. Widevine is supplied through the official Chrome installation, not bundled separately. Offline downloads, lossless playback and seamless gapless playback remain unsupported.

Includes the automatic playback recovery, **r/R** repeat, **F5** reload and dependency security fixes from rc.2–rc.4.

## Validation and status

Prerequisite regressions pass, including untrusted downloads, failed installers, independent readiness checks and restart persistence/clearing. A prototype setup passed isolated installation and uninstall with existing prerequisites; official prerequisite download signatures were verified. See [setup details](https://github.com/trashpenguin/pomme-tui/blob/v0.2.6-rc.5/docs/windows-setup.md) and [verification](https://github.com/trashpenguin/pomme-tui/blob/v0.2.6-rc.5/VERIFICATION.md).

Fresh-machine prerequisite installation/post-reboot provisioning, USB/Bluetooth reconnection and extended playback soak remain unverified. This remains an unsigned **prerelease**.
