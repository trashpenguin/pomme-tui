# Pomme TUI 0.2.6-rc.4 — Dependency security fixes

Updates the native backend's certificate-trust dependencies for CVE-2026-111943. Users of earlier candidates should update to this rebuilt package.

- `rustls-webpki` 0.103.16 and both WebPKI root packages 1.0.10 address the emSign distrust advisories.
- Tokio 1.53.3 addresses a Unix-only I/O-safety advisory; the locked yanked `chacha20` package is updated to 0.10.2.
- The production lockfile scan reports zero known vulnerabilities, no unsoundness warnings and no yanked packages. The unmaintained build-time `paste` macro remains an explicit maintenance warning. See [audit details](https://github.com/trashpenguin/pomme-tui/blob/v0.2.6-rc.4/docs/rust-dependency-audit.md).

Includes automatic same-song playback recovery, **r/R** for repeat, and **F5** for engine reload from rc.2/rc.3. See [verification](https://github.com/trashpenguin/pomme-tui/blob/v0.2.6-rc.4/VERIFICATION.md) for validation and historical hardware checks.

This is an unsigned Windows x64 **prerelease**. Clean Windows/first-time prerequisite installation, USB/Bluetooth reconnection and extended playback soak testing remain outstanding. Realtek wired-output checks and isolated fresh sign-in passed on rc.3; those physical tests were not repeated for this dependency-only update.

## Update

Quit Pomme, extract `pomme-tui-0.2.6-rc.4-windows-x64.zip` into a new folder, and start `Pomme.exe`. The normal profile is retained. `pomme.cmd version` should report `0.2.6-rc.4`.

Matching release files:

- `pomme-tui-0.2.6-rc.4-windows-x64.zip`
- `pomme-tui-0.2.6-rc.4-source.zip`
- `SHA256SUMS-0.2.6-rc.4.txt`

Requires Windows 10/11 x64, an active Apple Music subscription, installed Chrome x64 Widevine, Microsoft Visual C++ x64 Runtime and WebView2. Widevine is not included. No offline downloads, lossless playback or seamless gapless playback is claimed.
