# Pomme TUI 0.2.6-rc.2 — Playback recovery

Fixes random playback stops caused by interrupted downloads and gaps in recovery handling. Pomme now reloads the same song automatically at its last audible position, with up to three attempts and 1-, 2-, and 4-second backoff. The interface shows **Reconnecting audio** and keeps pause/skip available.

## Fixes

- Preserve download/decoder failures instead of treating interrupted audio as a normal song ending.
- Cancel scheduled recovery when you pause, change tracks, clear the queue, or sign out.
- Make Play reload a failed track and prevent late events from rewinding the saved position.
- Allow slow, progressing downloads to reach the saved position; retry stalled lookups.
- Check audio-output health while the output queue is full, paused, or idle, and retain the output-recovery event during audio-thread shutdown.
- Bound playback network waits and distinguish transport/server errors from account, catalog, and rate-limit failures.

## Install or update

1. Quit Pomme and extract `pomme-tui-0.2.6-rc.2-windows-x64.zip` into a new folder.
2. Start `Pomme.exe`, or run `Install.ps1 -AddToPath` to update the command installation. Your normal Pomme profile is retained.
3. Run `pomme version` to confirm `0.2.6-rc.2`. Run `pomme doctor` if dependency setup fails.

Requires Windows 10/11 x64, an active Apple Music subscription, Chrome's installed x64 Widevine module, Microsoft Visual C++ x64 Runtime, and WebView2. Widevine is not included. Existing limitations remain: no offline downloads, lossless playback, or seamless gapless playback.
