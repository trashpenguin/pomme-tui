# Pomme TUI 0.2.6-rc.6 — Artwork, Search and Stats

Download **pomme-tui-0.2.6-rc.6-setup-x64.exe**, quit your existing Pomme session, then run setup and open Pomme. Your profile and sign-in are retained.

- **Library and Search.** Browse artists, albums and playlists with terminal artwork. Artist search now queries the Apple Music catalog directly. Open results to see songs and albums, and return to the same search selection.
- **Stats.** Open your top artists and albums, or play ranked songs. Click or press Enter to open a ranked album. Press **e** to play it in full.
- **Controls.** **F1** opens help for the current screen. **Ctrl+X** clears the focused queue. **r/R** cycles repeat and **F5** reloads from the main screen. Library categories each open their own page.
- **Mini player and Windows Terminal.** The mini player has a compact card with separate track details and aligned progress. Pomme’s apple logo appears beside the title in its Windows Terminal tab.

Setup checks for Chrome with Widevine, Microsoft Visual C++ x64 Runtime and WebView2. It downloads missing prerequisites from Google and Microsoft and verifies publisher signatures. Pomme requires Windows 10/11 x64, internet access and an active Apple Music subscription. The portable ZIP uses manually installed prerequisites.

This is an unsigned prerelease. First-time prerequisite installation and playback on a clean Windows machine still need testing. Offline downloads, lossless playback and seamless gapless playback are outside the supported feature set.
